The first version of this site went up the month I graduated, built around
the assumption that I was headed straight into research. A year in
Washington changed the shape of my work, so I rebuilt the site to match.
The [work page](/work/) now carries
the weight — projects with dates, numbers, and links.

It's a custom Jekyll theme on GitHub Pages, set in
[Fraunces](https://fonts.google.com/specimen/Fraunces),
[Newsreader](https://fonts.google.com/specimen/Newsreader), and
[Inter](https://fonts.google.com/specimen/Inter), with a few small
enhancements — cross-page view transitions, a theme toggle, some scroll
choreography — that degrade cleanly on older browsers. Writing a post is
still one Markdown file and a push, which is the property I most wanted to
keep. Source is [on GitHub](https://github.com/adm-2k/adm-2k.github.io).
